# Extension Source

This is the only web extension source folder in the repo.

Edit these files here:

- `manifest.json`
- `background.js`
- `content.js`
- `popup.html`
- `popup.js`
- `options.html`
- `options.js`
- `styles.css`

Notes:

- This folder is what the Safari extension target uses.
- Saved site rules are stored in `browser.storage.local` under the `sites` key.
